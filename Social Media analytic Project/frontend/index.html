Semester 4 Data Structures Project

Social media analytics made simple for viva and presentation.

Built by Haris, Zohaib, Zechriah, Azlan, Kashan, and Ismail

This project connects a C++ backend with a lightweight frontend to show how a stack, queue, binary tree, and linked list can be used in a mini social media system.

What The Project Demonstrates

Linked List Feed

Posts are shown as a small social feed so we can explain insert, traverse, and display operations.

Queue Alerts

Notifications use queue behavior to show first-in-first-out processing for system updates.

Friend Tree

The network page presents connections between group members using a binary tree style structure.

Stack History

Action history is kept ready for undo operations, which makes the stack concept easy to present.
